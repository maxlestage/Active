---
title: Traductions et formatage
description: Traduire une application avec active::i18n — messages ICU avec paramètres, règles de pluriel et de sélection pour de nombreuses langues — et formater nombres, montants, pourcentages et dates dans la langue du visiteur.
---

`active::i18n` apporte ce que donnent vue-i18n, les pipes d'Angular et FormatJS, sans dépendance : des **messages** avec paramètres, les **règles de pluriel** de chaque langue, et le **formatage des nombres, montants, pourcentages et dates**. La locale courante est un état : changer de langue met à jour chaque texte traduit sur place.

```rust
use active::i18n::{Date, DateStyle, I18n};
use active::prelude::*;
```

## Messages

```rust
let i18n = I18n::new("en")
    .messages("en", [
        ("title", "Your inbox"),
        ("unread", "{name}, you have {count, plural, =0 {no new messages} one {# new message} other {# new messages}}"),
    ])
    .messages("fr", [
        ("title", "Votre boîte"),
        ("unread", "{name}, vous avez {count, plural, =0 {aucun nouveau message} one {# nouveau message} other {# nouveaux messages}}"),
    ]);

let header = div()
    .child(h1().text_dyn(move || i18n.t("title")))
    .child(p().text_dyn(move || {
        i18n.t_with("unread", &[("name", "Ada".into()), ("count", 1200.into())])
    }));

button().on_click(move |_| i18n.set_locale("fr")).text("Français");
// « Ada, vous avez 1 200 nouveaux messages »
```

`I18n` est `Copy` : déplacez-le dans les closures, ou donnez-le à toute l'application avec `provide(i18n, …)` et lisez-le avec `expect_context::<I18n>()`. Un message est cherché dans la locale courante (`fr-CA`), puis sa langue (`fr`), puis la locale donnée à `I18n::new` ; un message absent affiche sa clé.

## Syntaxe des messages

Les messages suivent ICU MessageFormat, la syntaxe de vue-i18n, d'Angular et de FormatJS :

| Syntaxe | Résultat |
| --- | --- |
| `{name}` | la valeur ; un nombre est formaté pour la locale |
| `{n, plural, =0 {…} one {…} other {…}}` | la branche de `n` : d'abord `=n` exact, puis la catégorie de pluriel ; `#` est le nombre |
| `{kind, select, a {…} b {…} other {…}}` | la branche dont la clé est la valeur, sinon `other` |

Les branches s'imbriquent : `{n, plural, one {{who} a aimé} other {{who} et # autres ont aimé}}`. Les valeurs sont des `Arg`, créés depuis `&str`, `String` et n'importe quel nombre avec `.into()`.

## Règles de pluriel

`plural(locale, n)` donne la catégorie CLDR (`Zero`, `One`, `Two`, `Few`, `Many`, `Other`). Les règles couvrent l'anglais, le français (0 et 1 sont au singulier), l'espagnol, l'allemand, l'italien, le portugais, le néerlandais, les langues scandinaves, le polonais, le tchèque, le slovaque, le russe, l'ukrainien (`one`, `few`, `many`), l'arabe (les six), l'hébreu, le japonais, le chinois et le coréen (`other` seulement) ; les autres langues suivent la règle anglaise.

## Nombres, montants et pourcentages

```rust
use active::i18n::{format_currency, format_fixed, format_number, format_percent};

format_number("en", 1234.5);            // "1,234.5"
format_number("fr", 1234.5);            // "1 234,5" (espace fine insécable)
format_fixed("de", 1234.5, 2);          // "1.234,50"
format_currency("en", 1234.5, "USD");   // "$1,234.50"
format_currency("fr", 1234.5, "EUR");   // "1 234,50 €"
format_currency("ja", 1234.0, "JPY");   // "¥1,234"
format_percent("en", 0.256, 1);         // "25.6%"
```

Les séparateurs suivent chaque langue (l'espagnol et le polonais ne groupent qu'à partir de cinq chiffres, l'allemand de Suisse utilise `'`), et les devises ont leur symbole et leur nombre de décimales habituel. Sur `I18n`, `number`, `currency` et `percent` utilisent la locale courante.

## Dates

```rust
use active::i18n::{format_date, Date, DateStyle};

let d = Date::new(2026, 10, 15);        // ou Date::from_unix(secondes)
format_date("en-US", d, DateStyle::Short);  // "10/15/2026"
format_date("en-GB", d, DateStyle::Long);   // "15 October 2026"
format_date("fr", d, DateStyle::Full);      // "jeudi 15 octobre 2026"
format_date("es", d, DateStyle::Long);      // "15 de octubre de 2026"
format_date("de", d, DateStyle::Medium);    // "15.10.2026"
```

Les noms de mois et de jours existent en anglais, français (avec « 1er »), espagnol, allemand, italien, portugais et néerlandais ; les autres langues ont les chiffres ISO (`2026-10-15`) pour `Short` et l'anglais sinon. `i18n.date(d, style)` utilise la locale courante.
