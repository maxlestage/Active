---
title: Translations and formatting
description: Translate an app with active::i18n — ICU messages with placeholders, plural and select rules for many languages — and format numbers, currencies, percentages and dates in the visitor's language.
---

`active::i18n` brings what vue-i18n, Angular's pipes and FormatJS give, without a dependency: **messages** with placeholders, **plural rules** for each language, and **number, currency, percentage and date formatting**. The current locale is a state: switching language updates every translated text in place.

```rust
use active::i18n::{Date, DateStyle, I18n};
use active::prelude::*;
```

## Messages

```rust
let i18n = I18n::new("en")
    .messages("en", [
        ("title", "Your inbox"),
        ("unread", "{name}, you have {count, plural, =0 {no new messages} one {# new message} other {# new messages}}"),
    ])
    .messages("fr", [
        ("title", "Votre boîte"),
        ("unread", "{name}, vous avez {count, plural, =0 {aucun nouveau message} one {# nouveau message} other {# nouveaux messages}}"),
    ]);

let header = div()
    .child(h1().text_dyn(move || i18n.t("title")))
    .child(p().text_dyn(move || {
        i18n.t_with("unread", &[("name", "Ada".into()), ("count", 1200.into())])
    }));
// "Ada, you have 1,200 new messages"

button().on_click(move |_| i18n.set_locale("fr")).text("Français");
```

`I18n` is `Copy`: move it into closures, or give it to the whole app with `provide(i18n, …)` and read it with `expect_context::<I18n>()`. A message is looked up in the current locale (`fr-CA`), then its language (`fr`), then the locale given to `I18n::new`; a missing one shows its key.

## Message syntax

Messages follow ICU MessageFormat, the syntax of vue-i18n, Angular and FormatJS:

| Syntax | Result |
| --- | --- |
| `{name}` | the value; a number is formatted for the locale |
| `{n, plural, =0 {…} one {…} other {…}}` | the branch for `n`: exact `=n` first, then the plural category; `#` is the number |
| `{kind, select, a {…} b {…} other {…}}` | the branch whose key is the value, else `other` |

Branches nest: `{n, plural, one {{who} liked it} other {{who} and # others liked it}}`. Values are `Arg`s, made from `&str`, `String` and any number with `.into()`.

## Plural rules

`plural(locale, n)` gives the CLDR category (`Zero`, `One`, `Two`, `Few`, `Many`, `Other`). The rules cover English, French (0 and 1 are singular), Spanish, German, Italian, Portuguese, Dutch, the Scandinavian languages, Polish, Czech, Slovak, Russian, Ukrainian (`one`, `few`, `many`), Arabic (all six), Hebrew, Japanese, Chinese and Korean (`other` only); other languages use the English rule.

## Numbers, currencies and percentages

```rust
use active::i18n::{format_currency, format_fixed, format_number, format_percent};

format_number("en", 1234.5);            // "1,234.5"
format_number("fr", 1234.5);            // "1 234,5" (narrow no-break space)
format_fixed("de", 1234.5, 2);          // "1.234,50"
format_currency("en", 1234.5, "USD");   // "$1,234.50"
format_currency("fr", 1234.5, "EUR");   // "1 234,50 €"
format_currency("ja", 1234.0, "JPY");   // "¥1,234"
format_percent("en", 0.256, 1);         // "25.6%"
```

Separators follow each language (Spanish and Polish only group from five digits, Swiss German uses `'`), and currencies get their symbol and usual number of decimals. On `I18n`, `number`, `currency` and `percent` use the current locale.

## Dates

```rust
use active::i18n::{format_date, Date, DateStyle};

let d = Date::new(2026, 10, 15);        // or Date::from_unix(seconds)
format_date("en-US", d, DateStyle::Short);  // "10/15/2026"
format_date("en-GB", d, DateStyle::Long);   // "15 October 2026"
format_date("fr", d, DateStyle::Full);      // "jeudi 15 octobre 2026"
format_date("es", d, DateStyle::Long);      // "15 de octubre de 2026"
format_date("de", d, DateStyle::Medium);    // "15.10.2026"
```

Month and day names exist in English, French, Spanish, German, Italian, Portuguese and Dutch; other languages get ISO digits (`2026-10-15`) for `Short` and English otherwise. `i18n.date(d, style)` uses the current locale.
