title: Traducciones y formato
description: Traducir una aplicación con active::i18n — mensajes ICU con parámetros, reglas de plural y de selección para muchos idiomas — y dar formato a números, importes, porcentajes y fechas en el idioma del visitante.
---

`active::i18n` aporta lo que dan vue-i18n, los pipes de Angular y FormatJS, sin dependencias: **mensajes** con parámetros, las **reglas de plural** de cada idioma, y el **formato de números, importes, porcentajes y fechas**. El locale actual es un estado: cambiar de idioma actualiza en su sitio cada texto traducido.

```rust
use active::i18n::{Date, DateStyle, I18n};
use active::prelude::*;
```

## Mensajes

```rust
let i18n = I18n::new("en")
    .messages("en", [
        ("title", "Your inbox"),
        ("unread", "{name}, you have {count, plural, =0 {no new messages} one {# new message} other {# new messages}}"),
    ])
    .messages("es", [
        ("title", "Tu bandeja"),
        ("unread", "{name}, tienes {count, plural, =0 {ningún mensaje nuevo} one {# mensaje nuevo} other {# mensajes nuevos}}"),
    ]);

let header = div()
    .child(h1().text_dyn(move || i18n.t("title")))
    .child(p().text_dyn(move || {
        i18n.t_with("unread", &[("name", "Ada".into()), ("count", 1200.into())])
    }));

button().on_click(move |_| i18n.set_locale("es")).text("Español");
// «Ada, tienes 1200 mensajes nuevos»
```

`I18n` es `Copy`: muévelo a los closures, o dáselo a toda la aplicación con `provide(i18n, …)` y léelo con `expect_context::<I18n>()`. Un mensaje se busca en el locale actual (`es-MX`), luego en su idioma (`es`), luego en el locale dado a `I18n::new`; un mensaje que falta muestra su clave.

## Sintaxis de los mensajes

Los mensajes siguen ICU MessageFormat, la sintaxis de vue-i18n, Angular y FormatJS:

| Sintaxis | Resultado |
| --- | --- |
| `{name}` | el valor; un número se formatea para el locale |
| `{n, plural, =0 {…} one {…} other {…}}` | la rama de `n`: primero `=n` exacto, luego la categoría de plural; `#` es el número |
| `{kind, select, a {…} b {…} other {…}}` | la rama cuya clave es el valor, si no `other` |

Las ramas se anidan: `{n, plural, one {A {who} le gustó} other {A {who} y # más les gustó}}`. Los valores son `Arg`, creados desde `&str`, `String` y cualquier número con `.into()`.

## Reglas de plural

`plural(locale, n)` da la categoría CLDR (`Zero`, `One`, `Two`, `Few`, `Many`, `Other`). Las reglas cubren inglés, francés (0 y 1 son singular), español, alemán, italiano, portugués, neerlandés, las lenguas escandinavas, polaco, checo, eslovaco, ruso, ucraniano (`one`, `few`, `many`), árabe (las seis), hebreo, japonés, chino y coreano (solo `other`); los demás idiomas usan la regla inglesa.

## Números, importes y porcentajes

```rust
use active::i18n::{format_currency, format_fixed, format_number, format_percent};

format_number("en", 1234.5);            // "1,234.5"
format_number("es", 12345.5);           // "12.345,5" (el español agrupa desde cinco cifras)
format_fixed("de", 1234.5, 2);          // "1.234,50"
format_currency("en", 1234.5, "USD");   // "$1,234.50"
format_currency("es", 1234.5, "EUR");   // "1234,50 €"
format_currency("ja", 1234.0, "JPY");   // "¥1,234"
format_percent("en", 0.256, 1);         // "25.6%"
```

Los separadores siguen cada idioma (el español y el polaco solo agrupan desde cinco cifras, el alemán de Suiza usa `'`), y las monedas tienen su símbolo y su número de decimales habitual. En `I18n`, `number`, `currency` y `percent` usan el locale actual.

## Fechas

```rust
use active::i18n::{format_date, Date, DateStyle};

let d = Date::new(2026, 10, 15);        // o Date::from_unix(segundos)
format_date("en-US", d, DateStyle::Short);  // "10/15/2026"
format_date("en-GB", d, DateStyle::Long);   // "15 October 2026"
format_date("fr", d, DateStyle::Full);      // "jeudi 15 octobre 2026"
format_date("es", d, DateStyle::Full);      // "jueves, 15 de octubre de 2026"
format_date("de", d, DateStyle::Medium);    // "15.10.2026"
```

Los nombres de meses y días existen en inglés, francés, español, alemán, italiano, portugués y neerlandés; los demás idiomas reciben las cifras ISO (`2026-10-15`) para `Short` y el inglés en lo demás. `i18n.date(d, style)` usa el locale actual.
